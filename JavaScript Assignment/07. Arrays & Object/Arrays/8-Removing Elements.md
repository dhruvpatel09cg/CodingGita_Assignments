# 8. Removing Elements

Q1) Which method removes the **last** element of an array?

=> `pop`

Q2) Which method removes the **first** element of an array?

=> `shift`

Q3) Given `let nums = [100, 200, 300, 400, 500];`, what does `nums.pop();` do, and what will the array contain after calling it?

=> `nums.pop();` will remove the last element of the array.

`[ 100, 200, 300, 400 ]`

Q4)  After the previous operation, what does `nums.shift();` do, and what will the remaining array contain?

=> `nums.shift();` will remove the first element of array.

`[ 200, 300, 400 ]`

Q5)  Do `pop()` and `shift()` return the removed element, or do they only modify the array?

=> Yes, both `pop` and `shift` returns the removed element.
