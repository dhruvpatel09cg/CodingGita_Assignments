# 3. Accessing Values in an Array

Q1) What do you use to access a specific value stored in an array?

=> index of the value

Q2) Given `var students = ["Jenil", "Mahir", "Priyesha"];`, what does `console.log(students[0]);` output?

=> Jenil

Q3) For the same array, what does `console.log(students[2]);` output?

=> Priyesha

Q4) What value does JavaScript return if you attempt to access an index that does not exist (such as `students[10]`)?

undefined

Q5) Write a line of code to log the first element of an array named `colors`.

```js
const colors = ["Blue", "Red", "Pink"];
console.log(colors[0])
```
