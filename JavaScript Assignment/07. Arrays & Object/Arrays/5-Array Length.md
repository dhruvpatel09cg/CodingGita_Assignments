# 5. Array Length

Q1) What is the name of the built-in property available on every JavaScript array that tells you how many items it contains?

=> length

Q2) Given `var arr = [1, 2, 3, 4];`, what does `console.log(arr.length);` output?

=> 4

Q3) If an array is empty (contains no elements), what is its `length` property equal to?

=> 0

Q4) Why is the `length` property particularly useful when working with arrays?

=> `length` tells us how many elements are there in an array so we need not to manually count it.

Q5) Is `length` a function call (requiring parentheses `()`) or a property?

=> `length` is not a function call, there is no need to use `()`.
