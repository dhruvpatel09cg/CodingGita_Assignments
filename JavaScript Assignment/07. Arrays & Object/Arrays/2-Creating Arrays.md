# 2. Creating Arrays

Q1) What are the two ways mentioned in the notes to create an array in JavaScript?

=> Using square brackets

=> Using the Array constructor

Q2) Which method of creating an array is recommended by the notes?

=> Using square brackets to make an array is recommended

Q3) Write the syntax to create an array named `students` containing the names `"Jenil"`, `"Mahir"`, `"Priyesha"`, and `"Yashvi"` using the recommended method.

```js
const students = ["Jenil", "Mahir", "Priyesha", "Yashvi"];
```

Q4)  Write the syntax to create an array named `marks` containing `85`, `90`, and `78` using the `Array` constructor.

```js
const marks = new Array(85, 90, 78);
```

Q5) What keyword is used when instantiating an array using the constructor approach?

=> `new`
