# 1-What Is an Array?

Q1) What is the definition of an array in JavaScript?

=> An array is an ordered collection of values.

Q2) What is the technical term for the position of a value inside an array?

=> Index

Q3) At which number does the index of an array always start?

=> 0 (Zero)

Q4) Given the array `var numbers = [10, 20, 30, 40];`, what value is stored at index `2`?

=> 30

Q5) For the same array `var numbers = [10, 20, 30, 40];`, what is the index of the number `40`?

=> 3
