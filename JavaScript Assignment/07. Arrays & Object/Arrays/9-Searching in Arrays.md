# 9. Searching in Arrays

Q1) What does the `indexOf()` method return when the searched value is found in the array?

=> It returns the index of the value found.

Q2) What does `indexOf()` return when the value is **not** present in the array?

=> When the value is **not** present in array `indexOf()` returns `-1`

Q3) Given `const names = ["Jenil", "Mahir", "Arjun"];`, what does `console.log(names.indexOf("Mahir"));` output?

=> 1

Q4) For the same array, what does `console.log(names.indexOf("Krishna"));` output?

=> -1

Q5) Write a line of code that finds the index of `"Priyesha"` in an array named `students`.

```js
const students = ["Freya", "Reet", "Priyesha", "Ved"];
console.log(students.indexOf("Priyesha"));
```
