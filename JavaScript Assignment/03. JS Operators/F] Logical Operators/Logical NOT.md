# Logical NOT

Q1) A user is not banned (`isBanned = false`). Check if they can login by negating `isBanned` using `!`.

```js
let isBanned = false;
let canLogin = !isBanned
console.log("Can login?",canLogin)
```

Q2) A task is not completed (`isCompleted = false`). Check if it is still pending using `!`.

```js
let isCompleted = false;
let stillPending = !isCompleted
console.log("Is task still pending?",stillPending)
```

Q3) A light is on (`isOn = true`). Check if it is off using `!`.

```js
let isOn = true;
let isOff = !isOn
console.log("Is the light off?",isOff)
```

Q4) A subscription is not active (`isActive = false`). Check if the user cannot access premium content using `!`.

```js
let isActive = false;
let cannotAccess = !isActive
console.log("User cannot access premium?",cannotAccess)
```

