# Strict Inequality

Q1) Check whether `"18" !== 18` returns true or false.

```js
console.log("18" !== 18)
// Output: true
```

Q2) Check if `0 !== false` and `null !== undefined`.

```js
console.log(0 !== false) // Output: true
console.log(null !== undefined) // Output: true
```

Q3) Predict the output:

```js
console.log(5 !== "5"); // Output: true
console.log(true !== 1); // Output: true
```

Q4) Predict the output:

```js
console.log("" !== 0); // Output: true
console.log(NaN !== NaN); // Output: true
```

Q5) Write a condition that checks if a variable `input` is strictly not equal to the string `"0"`.

```js
let input;
console.log(input!=="0")
// Output: true
```
