# Simple Assignment

Q1) Store a student’s name as `"Priya"` and marks as `92` using the assignment operator.

```js
let name = "Priya"
let marks = 92
```

Q2) Create a variable `score` and assign it the value `0`.

```js
let score = 0
```

Q3) Assign the value `50` to three variables `a`, `b` and `c` using a single chained assignment.

```js
let a, b, c;
a=b=c=50
```

Q4) Predict the output:

```js
let x;
x = 100;
console.log(x);
// Output: 100
```

Q5) What is the result of `let m = 15; m %= 0;`? Explain.

Output: NaN => remainder of a number divided by 0 will be Not a Number
