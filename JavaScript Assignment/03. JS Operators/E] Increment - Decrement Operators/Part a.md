# Part A

Q1) A counter starts at `5`. Use the increment operator to increase it by 1 and print the new value.

```js
let counter = 5;
counter++;
console.log(counter);
```

Q2) A player has `3` lives. Use the decrement operator to reduce one life and print the remaining lives.

```js
let lives = 3;
lives--
console.log(lives)
```

Q3) Start with `score = 10`. Increase the score using `++` and print it.

```js
let score = 10;
score++
console.log(score)
```

Q4) Start with `items = 8`. Decrease the items using `--` and print it.

```js
let items = 8;
items--
console.log(items)
```

Q5) Declare `count = 0`. Increment it twice and print the final value.

```js
let count = 0;
count++ ++
++count
console.log(count)
```
