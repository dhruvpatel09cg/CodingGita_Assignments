Q20. Predict the output of the following code and explain why:

    let value = 25;
    console.log(typeof value);
    value = "JavaScript";
    console.log(typeof value);
    value = false;
    console.log(typeof value);

  Ans: 
    Output:
    
      number
      string
      Boolean

  Reason:

    As JS is a Dynamically typed language it changes type of variable according to the value assigned 
    in it.
