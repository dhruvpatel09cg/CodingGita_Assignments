Q1. What is JavaScript?

    JavaScript is a high-level, dynamically typed programming language used to create interactive websites
    and applications.

Q2. Who created JavaScript and in which year?

    JavaScript was created by Brendan Eich at Netscape in year 1995.

Q3. What was the original name of JavaScript?

    JavaScript was originally named as Mocha, then LiveScript and finally JS.

Q4. Is JavaScript the same as Java? Give one major difference.

    JavaScript is not the same as Java. The major difference between them is that JS is Dynamically typed
    programming language while Java is Statically typed programming language.

Q5. What does it mean when we say JavaScript is a high-level programming language?

    High-level programming language basically means language which uses human-readable instructions as code.

Q6. Is JavaScript a compiled language or an interpreted language? Explain briefly.

    JavaScript is an interpreted language which is executed by JS engine built in browser used. The engine
    reads and executes the code line-by-line or step-by-step.
